# FS Reports Acceptance Checklist

## Visual Quality

- [ ] Large decorative icons have been removed from report panels.
- [ ] First viewport contains useful financial content, not empty visual space.
- [ ] Charts have consistent colors, labels, legends, and readable axes.
- [ ] Header is compact and does not dominate the viewport.
- [ ] Desktop layout uses available screen width efficiently.
- [ ] Mobile and tablet layouts do not overlap or clip content.

## Finance Reporting

- [ ] Revenue, COGS, gross profit, opex, and operating result tie to ledger data.
- [ ] Balance sheet categories tie to chart-of-account categories.
- [ ] Common-size P&L percentages calculate against revenue.
- [ ] Common-size balance sheet percentages calculate against total assets.
- [ ] Current ratio and debt-to-equity calculate from selected data.
- [ ] Cash and working capital views include clear GL-data caveats.

## CFO Insight

- [ ] Every page includes a short finance narrative.
- [ ] Overview includes CFO exceptions.
- [ ] Exceptions have severity levels.
- [ ] Monthly variance analytics identify best and worst months.
- [ ] Profit bridge reconciles revenue to operating result.
- [ ] Insight text updates when filters change.

## Drilldown And Interactivity

- [ ] Statement rows drill down to supporting ledger lines.
- [ ] Chart segments support drilldown or filtering.
- [ ] Drilldown panel shows selected amount, transaction count, and account mix.
- [ ] Breadcrumbs show what the user selected.
- [ ] Clear drilldown/reset controls work consistently.
- [ ] Filtered ledger export works.
- [ ] Selected drilldown export works.

## Reconciliation And Controls

- [ ] Total debits and credits are shown.
- [ ] Net ledger total is shown and equals zero for the full dataset.
- [ ] Balanced journal entry count is shown.
- [ ] Mapped vs unmapped ledger lines are shown.
- [ ] Active vs inactive accounts are shown.
- [ ] Date coverage is shown.
- [ ] Failed checks are visibly highlighted.

## Browser Verification

- [ ] Verify at `1366x768`.
- [ ] Verify at `1600x900`.
- [ ] Verify at `1024x768`.
- [ ] Verify at mobile width.
- [ ] Test every tab.
- [ ] Test each filter menu.
- [ ] Test search.
- [ ] Test reset.
- [ ] Test export.
- [ ] Test statement drilldowns.
- [ ] Test chart click interactions.
